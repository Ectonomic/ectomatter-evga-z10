# The Z10 core's typefaces

The typefaces the Z10's art draws its legends in, for Ectomatter to set them anew (the Key lab's Legends section).

- `BarlowSemiCondensed-SemiBold.ttf`: Barlow Semi Condensed SemiBold, by The Barlow Project Authors, under the SIL Open Font License 1.1 (`OFL.txt`).
- `Z10Symbols-Bold.ttf`: the signs Barlow lacks (▲ ◀ ▶ ▼ ⊞ ≡), cut from DejaVu Sans Bold 2.37 and renamed, as its license asks of a changed font (`DejaVu-LICENSE.txt`). Built by `tools/z10-art/print.py fonts`.
